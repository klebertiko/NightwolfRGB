O RGB do PC, no seu controle.

Livre-se do bloatware. Sem conta. O OpenRGB vem no bundle — 100% compatível. Você pinta o hardware. Pronto.

OpenRGB. 100% compatível. No bundle.

Nightwolf não inventa outro SDK. Pinta em cima do OpenRGB. O app sobe o engine. Porta 6742. Neste PC: protocolo v5. Identidade, modos, zonas, LED a LED, matrix, resize, .orp nativo.

Crédito: openrgb.org · GitLab · CalcProgrammer1/OpenRGB

Antes de pintar: libere o hardware.

A Limpeza lista processos RGB que brigam pela mesma placa. Detecta iCUE, Armoury Crate, Aura, Synapse, Mystic Light, CAM, RGB Fusion, Polychrome, SignalRGB, G HUB, SteelSeries GG, NGENUITY e afins. Fecha só o que você pede — e só quando você manda.

Primeiro: pinte na Luz.

Escolha o device, a zona, o LED. Header vazio? O slider manda o tamanho. Direct, Static, Breathing, Color Cycle — os modos que a placa declara, com os parâmetros que cada um aceita.

Depois: anime no hardware.

Estático, Respirar, Estrobo, Arco-íris, Espectro, Sequência. Velocidade no slider. Direct, sem microfone. Sem loja. Sem baixar pacote.

Guarde o estado. Ou o perfil nativo.

Cena Nightwolf grava o estado neste app. Perfil .orp é o arquivo do OpenRGB: carregar, salvar, apagar. Os dois na mesma tela — separados de propósito.

Instalar

Uma linha. PowerShell ou Git Bash. O script instala a build fechada. Depois, nightwolfrgb update ou Atualizar no app. Os dois também checam o OpenRGB.

PowerShell

irm https://github.com/klebertiko/NightwolfRGB/releases/latest/download/install.ps1 | iex

Git Bash

curl -fsSL https://github.com/klebertiko/NightwolfRGB/releases/latest/download/install.sh | bash
